একবার নতুন হিসাব সেটআপ

এই কাজ কম্পিউটার থেকে করুন। আপনার পুরোনো হিসাব ও ছবি মুছবে না। প্রস্তুতির সময় DSO জমা বন্ধ থাকবে।

  1. Firebase Realtime Database থেকে Export JSON করে নিজের কম্পিউটারে backup রাখুন।
  2. ZIP-এর Billing_Free_Transition_Rules.json-এর Rules প্রকাশ করুন। এতে পুরোনো রিপোর্ট/স্লিপে নতুন লেখা বন্ধ হবে।
  3. নিচে ওই backup নির্বাচন করে যাচাই করুন।
  4. দেখানো সংশোধন ও সতর্কতা পড়ে স্থানান্তর শুরু করুন।

এই Rules বর্তমান public password login-এর নিরাপত্তা সমাধান নয়; শুধু পুরোনো লেখার পথ বন্ধ করে নতুন কাঠামোয় যাওয়ার জন্য।

যাচাই এখনও হয়নি।
